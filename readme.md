# BEFORE YOU

> someone was here before you.

**BEFORE YOU** is an experimental horror website built around a simple idea:

Someone was here before you.  
They left something behind.  
You found it.  
Now you decide what the next person finds.

The experience focuses on atmosphere rather than traditional horror imagery — old-web aesthetics, unsettling typography, sound, visual interference, and messages left by strangers.

## The Experience

**ENTRY**  
A quiet introduction to a forgotten-looking corner of the internet.

**FOUND**  
Read something left behind by another visitor.

**LEAVE**  
Leave a message for whoever arrives after you.

There is no monster to find, no puzzle to solve, and no final reveal.

The uncertainty is the point.

## Design

BEFORE YOU draws inspiration from the feeling of neglected websites from the early web:

- dark, imperfect interfaces
- distressed typography
- red and monochrome accents
- subtle glitches and interference
- ambient sound
- minimal interaction
- mobile-first responsive design

The goal is to make the website feel discovered rather than presented.

## Built With

- HTML

- JavaScript
- Node.js

## Local Development

### Requirements

- Node.js 20 or newer
- npm

### Install

```bash
npm install
```

### Run

```bash
npm start
```

Then open the local address shown by the server.

## Project Status

BEFORE YOU is an ongoing experimental project.

The interface, atmosphere, and interaction may evolve over time.
